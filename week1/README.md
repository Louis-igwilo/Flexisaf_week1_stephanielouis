# Shopping Total calculator
## About

This is a simple calculator to check the total sum of items gotten as well as the quantity and print a reciept as well as the sum

The program asks the user for
- The name of the item
- The price for that item
- The quantity of that item

It then displays the name and total cost for each item and the total cost all together.

## How to run
- Make sure python is installed
- Open the project folder in vs code
- Open the terminal
- Run
